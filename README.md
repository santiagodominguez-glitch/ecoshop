# Ecoshop

Tienda en línea de equipos eficientes (Actividad 2, Ingeniería Web I). Páginas: `index.html`, `catalogo.html`, `nosotros.html`, `contacto.html`.

## Cómo abrirla
Abre `index.html` en el navegador (necesita internet para Bootstrap y Google Fonts).

## Sass
Los estilos se escriben en `scss/estilos.scss` (con el parcial `scss/_variables.scss`) y se compilan a `css/estilos.css`:

    npm install
    npx sass scss/estilos.scss css/estilos.css --no-source-map
